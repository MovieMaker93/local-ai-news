llama.cpp fixes a Vulkan bug that silently corrupted tokens on AMD and NVIDIA GPUs

Release b10677 fixes a missing view-alias dependency in ggml_vk_graph_optimize that reordered aliased reads and writes, producing silently wrong tokens, run-to-run output changes, and invalid speculative-decoding acceptance. It hits Qwen3.8's recurrent state hardest; CUDA was unaffected. If you run Vulkan builds, update now.
