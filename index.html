NVIDIA ships Kumo Tabular, an open-weights tabular-prediction model that needs no training pass

NVIDIA released Kumo Tabular, an open-weights foundation model for tabular prediction that labels new tables in a single forward pass with no training or feature engineering step. It comes in three sizes (28M-215M parameters), was pretrained only on synthetic data, ranks first on TabArena, BeyondArena, TALENT and ScoringBench, and ships under the OpenMDW-1.1 license for commercial use, with code and weights on GitHub and Hugging Face.

H Company published the Holo4 family of generalist computer-use VLMs: Holo4-27B (dense, built on Qwen3.8-27B, CC BY-NC 4.0) and Holo4-35B-A3B (MoE with 3B active params, Apache 2.0, self-hostable for commercial use). 05

STEPQuant: when and where errors matter in delta-rule recurrent-state quantization

Shows that quantizing the fixed-size recurrent state of delta-rule linear-attention models to low precision causes severe accuracy degradation via error propagation, and proposes state-specific quantization that preserves accuracy under a reduced memory footprint for concurrent serving.

arXiv · 2026-09-29

LeapQuant: efficient linear attention with accurate recurrent-state quantization

Targets hybrid LLMs with linear attention (Gated DeltaNet, Kimi Delta Attention) and quantizes the fixed-size recurrent state accurately, compressing long context and cutting inference memory while limiting accuracy loss.

MetaCtrl: a metacognitive controller for shorter, cheaper reasoning

Adds a metacognitive controller that regulates reasoning-token allocation in large reasoning models, cutting redundant chain-of-thought on simple problems while preserving accuracy — reducing per-query token cost at inference.
