SparseDecoding: pruning LLMs scored on the model's own generated tokens

SparseDecoding: pruning LLMs scored on the model's own generated tokens

A training-free, layer-wise pruning method that computes importance on self-generated (decoded) tokens rather than natural sequences, closing the distribution-shift gap and cutting memory-bound decoding latency while keeping accuracy.

arXiv · 2026-10-08

Rounding in preconditioner space redesigns 4-bit AdamW optimizer-state quantization

Re-derives 4-bit quantization of AdamW optimizer states in preconditioner space instead of state space, reducing adaptive-update perturbation and cutting memory for fine-tuning runs.

arXiv · 2026-10-08

When lower reconstruction loss hurts: robust refinement for low-bit LLM quantization

Shows that minimizing reconstruction loss in weight-only PTQ can degrade performance under activation-distribution shift, and proposes a distributionally robust refinement that beats standard low-bit quantization on held-out tasks.

arXiv · 2026-10-08

Where draft trees lose target mass: exit-guided speculative decoding

Proves an exit-law bound on accepted block length for tree-based speculative decoding and uses target feedback to improve draft trees for higher acceptance rates.

arXiv · 2026-10-08

RaRaCache reuses the KV cache across models of different sizes

Enables KV-cache transfer between different-sized models via rank-disagreement-based selective recomputation, avoiding a full context re-prefill when switching models — a direct serving-cost win for multi-model local stacks.
