New inference primitive

llama.cpp adds Decision Models support with a new /v1/systemone endpoint

llama.cpp merged PR #29818 on October 2, adding a POST /v1/systemone API to llama-server for typed decision models (laya, julia-1, lev, openjev, kev). A model receives a state — text, JSON, or a screenshot for vision-capable weights — plus typed questions and returns a probability for each option in a single forward pass, skipping token-by-token generation. The endpoint follows the Typesafe.ai SystemOne API format and ships with five open GGUF decision models, a relevant new primitive for self-hosted agent and automation stacks.
