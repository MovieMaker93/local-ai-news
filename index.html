Online draft co-training for speculative decoding in long-context RL post-training

NVIDIA's system enables online co-training of speculative drafts (EAGLE-3, DFlash, DSpark) by merging rank-local branch attention into packed zigzag-ring context-parallel attention, delivering 1.50–1.88x end-to-end roll-out speedups on targets up to 122B while preserving the RL trajectory.

Forward-free LLM depth pruning via weight redundancy

Weight-Redundancy Pruning removes whole Transformer blocks without any forward passes, scoring inter-block similarity from weight redundancy instead of activation statistics — cutting inference cost while avoiding calibration-data forward passes entirely.

arXiv · 2026-09-09

RiLM: parameter-efficient language modeling via geodesic decoding

RiLM removes the output softmax matrix entirely for sub-million-parameter models by decoding over squared geodesic distance on a Riemannian manifold. HypRiLM, at ~290k params, reaches 54.2 validation perplexity on WikiText-2 versus 87.6 for the flat variant, aimed at edge deployment.

arXiv · 2026-09-09

DiffLUT-Net: differentiable training of FPGA LUT networks

An FPGA-native neural network built from six-input lookup tables with learnable connectivity, trained end-to-end via differentiable training rather than converting pretrained quantized models — eliminating multiply-accumulate operations in favor of LUT-based on-chip execution.

Readable schemas beat fixed keys for SLM vehicle-agent function calls

A study under strict memory and latency constraints for on-device in-vehicle assistants shows readable natural-language schemas outperform fixed opaque keys for small-model function-call accuracy in resource-limited deployments.
